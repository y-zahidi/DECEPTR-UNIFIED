# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in DECEPTR-UNIFIED, please report it responsibly.

**Do NOT open a public issue.**

Instead, email: **yassirzahidi8@gmail.com**

Include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

I'll acknowledge your report within 48 hours and aim to provide a fix or mitigation within 7 days.

## Scope

This policy covers the DECEPTR-UNIFIED codebase, Docker configurations, and API endpoints. It does **not** cover third-party components (Elasticsearch, OpenCTI, CALDERA, etc.) — report those to their respective maintainers.

## Supported versions

| Version | Supported |
